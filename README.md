# Drive（ドライブ）

端末は手前から1列目、2列目、3列目。列は1〜3、各列は2〜4枚。コントローラは1列目の向かって左端で、ほかの端末は1列目の右へ、次に2列目の左から右、その次に3列目の左から右へ並ぶ。

色が出るのは1列だけ。その列の緑が1つで、ほかはその列の赤。緑のすき間をめがけて、手前から奥へボールを運ぶ。次の緑は前の緑のとなりだけで、同じ枚数の列では同じ位置が続かない。1列目が2枚で左が緑のとき、2列目が3枚なら右端は選べない。

1列を出しておく時間は2〜10秒。停止するまで繰り返す。止めるとコントローラはメニューに戻り、ほかの端末は無色になる。

ローカル確認: `npm test`、`npm run dev`。
